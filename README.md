# Luwi Themes

Free premium WordPress themes for [LuwiPress](https://luwipress.com).
Each theme is a different palette/feel applied to the same global structure —
Playfair Display + Inter + JetBrains Mono pairing, sticky header, mega menu,
WooCommerce-ready, Elementor-compatible.

| Theme | Direction | Status |
|---|---|---|
| [`luwipress-gold/`](luwipress-gold/) | Artisan Heritage — Gold accent palette, cream cream background, V32-style info-bar | ✅ Available |
| Luwi Emerald | Botanical Modern — emerald + warm white | Planned |
| Luwi Ruby | Bold Luxe — ruby + obsidian | Planned |

## Install

Each theme is self-contained inside its own folder. To install:

1. Download the theme folder as a `.zip` (or clone the whole repo and zip the folder)
2. WP Admin → Appearance → Themes → Add New → Upload Theme → activate
3. See the per-theme `README.md` for plugin requirements + Elementor Kit import order

## Pairs with

[LuwiPress core plugin](https://luwipress.com) — adds AI chat, knowledge graph,
content scheduler, multilingual translation. The themes work without it,
but light up additional features when both are active.
